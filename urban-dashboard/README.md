## Experimental Pipeline Visualization

The **Urban Dashboard** is currently in an **experimental phase**, serving primarily as a high-performance visualization layer for the outputs generated by the project's data pipeline. It provides a bridge between raw data processing (Python scripts) and spatial analysis.

### Core Capabilities
- **Spatial DNA Visualization**: Renders high-resolution "Stop DNA" results (hubs) directly from GeoPackage (`.gpkg`) artifacts using `better-sqlite3`.
- **Large-scale Matrix Analysis**: Leverages **DuckDB** to perform high-speed server-side queries on massive Parquet matrices (POI pulls, population density).
- **Advanced Rendering**: Uses **Deck.gl** for high-performance rendering of:
  - **Scatterplot Layers**: For hub locations and their respective grades (A+ to F).
  - **Hexagon Layers**: For spatial aggregation of real-estate transactions and valuation data.
  - **GeoJSON Layers**: For population grids and infrastructure networks.
- **Interactive Inspection**: Allows deep-diving into specific nodes to analyze catchment areas, POI distributions, and demographic profiles.

### Technical Stack
- **Framework**: Next.js 15+ (App Router) with React 19.
- **Visualization**: Deck.gl & MapLibre GL.
- **Data Engines**: DuckDB-Wasm/Async & SQLite (GeoPackage).
- **State**: Zustand for reactive UI and map state coordination.
- **UI Components**: Tailwind CSS 4 & shadcn/ui.

### Usage in Pipeline
The dashboard is designed to be used alongside the `dev.sh` orchestrator. As the pipeline completes steps like `15_compute_stop_dna.py`, the results become immediately available for visual audit in the dashboard by selecting the respective city.
